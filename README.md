## Usage

Launch the app, in it, select “map” mode or “stats”.
On map mode, users can interact with the path by dragging the start and end locations,
the program will generate a path between them. The conditions for the path are determined by the selection on the top side.
“Fastest path” shows a more dangerous path but with a shorter distance. “Safest Path” shows a path that prioritizes safety over length, the recommended path is a combination of both of them.
 Using the top tabs, users can select different lenses: wind, that shows directions and strength by arrows, and their length. The precipitation map shows the hardness of weather conditions,
 lighter blue shows lighter precipitation and therefore more danger, while darker colors indicate higher precipitation. Danger lens shows the danger of weather conditions,
with no shading at all (clean green/blue), it is no danger at all, while Purple shows the highest combined danger. (Green - yellow - red - purple, lowest to highest).
By clicking “home” the users can go back to the main menu. After selecting the “Stats” button, the user will be able to input the Aircraft model, maximum speed, cruise (optimal) speed.
By selecting the start and end coordinates, just like on the map. By putting the coordinates for an individual cell, the program will display elevation, wind speed, wind direction,
temperature, chance of precipitation, and weather intensity. The calculate button recalculates the data based on the inputted variables.
